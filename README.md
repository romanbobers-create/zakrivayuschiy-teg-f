# Закрывающий тег

Учебный проект по вёрстке, выполненный в рамках курса «Фронтенд-разработчик» от Яндекс Практикума. 

Это интерактивная страница-дневник с личными воспоминаниями о пройденном пути — от нулевого до финального спринта. Каждая карточка отражает определенный этап обучения и сопровождается подобранными под настроение фотографиями.

## 🛠️ Технологии и реализация:
*   **HTML5:** семантическая вёрстка, доступность (ARIA).
*   **CSS3:** 
    *   Построение сеток на Flexbox.
    *   Адаптивная и «резиновая» вёрстка (медиазапросы, `clamp()`).
    *   Сложный фон из множественных градиентов.
    *   CSS-фильтры для стилизации изображений (инверсия, контраст, размытие и др.).
    *   Работа с текстовой обводкой (`text-stroke`) и режимами наложения (`mix-blend-mode`).
*   **Анимации:** Оживление SVG-иконки сердца при помощи `@keyframes` и плавных переходов `transition`.
*   **JavaScript:** Логика постановки лайков (переключение классов и смена текста на кнопке).
*   **Модальное окно:** Реализовано с помощью нативного HTML-тега `<dialog>` и псевдоэлемента `::backdrop`.

## 📂 Структура проекта:
*   `fonts/` — шрифты (Inter, PressStart2P).
*   `images/` — графика и фавиконки.
*   `scripts/` — скрипты.
*   `styles/` — CSS-файлы (переменные, глобальные стили, анимации, основной файл стилей).
*   `svg/` — спрайты.
